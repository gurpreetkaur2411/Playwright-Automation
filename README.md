# Playwright Automation

This repository contains beginner-friendly JavaScript exercises and notes as the foundation for learning automation.

## Contents

- `01_chapter_JS_basic/` — first JavaScript program and basic math examples.
- `02_chapter_JS_Keywords_Identifiers/` — JavaScript keywords, identifiers, naming rules, comments, and related examples.

## Running an example

Install [Node.js](https://nodejs.org/), then run a JavaScript file from the repository root:

```bash
node 01_chapter_JS_basic/01_HelloWorld.js
```

You can run any of the other `.js` exercises in the same way by replacing the file path.
